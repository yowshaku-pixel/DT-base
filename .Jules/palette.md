## 2025-05-15 - [Icon-only Accessibility Pattern]
**Learning:** Icon-only buttons often rely only on 'title' attributes, which are insufficient for screen readers. Using Lucide icons without 'aria-label' or 'aria-expanded' for toggles is a recurring accessibility gap.
**Action:** Always provide 'aria-label' for icon-only buttons and 'aria-expanded' for state-driven UI toggles.
